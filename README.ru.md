# Sea Battle

[English](README.md) · [Русский](README.ru.md)

Простая консольная игра «Морской бой» на C++.

## Возможности

- Компьютер случайно расставляет 5 кораблей на поле 10×10
- Нужно потопить их все, угадывая координаты
- Обозначения: `X` — попадание, `O` — промах, синие клетки — не проверены

## Начало работы

Нужен компилятор C++ (например, `g++`).

```bash
g++ SeaBattle.cpp -o SeaBattle
./SeaBattle
```
